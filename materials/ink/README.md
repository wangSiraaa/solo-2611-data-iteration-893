# 格面受墨量与纸张配给（虚构印模，离线复核）

本目录只做数据复核，不控制任何实体设备。所有数值按精确有理数解释。
印模沿用旧档的 `cart_id` 分段线性平移路径与对应轮廓半宽/半高；流墨率恒为非负。
只碰边、只碰角没有面积贡献。

## 场景 A：单格、单印模、静止（备忘录里的两个数）

一格 `[0,1]×[0,1]`，时限 4，印模静止、两半尺寸均为 1/2、流墨率 1。
两只印模各占一张试版，彼此不重叠：

- 印模 `S`，中心 `(5/4, 1/2)`：`ink = (1/2 × 1) × 1 × 4 = 1`
- 印模 `L`，中心 `(3/4, 1/2)`：`ink = 1 × 1 × 4 = 3`

印模 `S` 只有右半压在格内（宽 1/2），`L` 整只落在格内（宽 1）。

## 场景 B：斜向平移，动作段内面积改变

一格 `[0,1]×[0,1]`，印模半尺寸 1/2×1/2、流墨率 1，中心从 `(1/2,1/2)`
斜线移到 `(3/2,3/2)`（[0,1] 内），之后静止。交叠面积在动作段内是分段
二次函数，精确积分得 `1/3`。用 `D` 印模。

## 纸张（闭区间门槛）

每格墨量落在纸种容许的**闭区间**内才合格；全部指定格合格才能用该纸种出一张。
薄纸仅收 `[0,2]`、厚纸仅收 `[2,4]`：`late`（墨量 3）只能用厚纸；`early`（墨量 1）
两种都行。厚纸已被更早的确认领完则 `late` 无法交付。加急权重：`early` 1，`late` 2，
所以资源紧张时优先保 `late`。

文件：
- `profiles.json` / `profiles_revised.json`：初版与修正轮廓；后续修订不改旧凭单；
- `motions.json`：印模轨迹（horizon 4）；
- `plate_early.json` / `plate_late.json` / `plate_diag.json`：试版格网；
- `plates.json`：纸张配给需求（含权重与闭区间）；
- `operations.jsonl`：可复跑操作流。
